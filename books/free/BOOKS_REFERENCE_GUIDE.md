## 📚 How to Download Each Book

### For Books with Direct Links (12 already downloaded)
1. They're in `books/free/` - check for license info in the PDF itself
2. Visit the source URL to confirm license terms

### For Books with Portal URLs
**OpenStax Books:**
1. Visit https://openstax.org
2. Search for the book by title
3. Click "Download" and choose PDF format
4. Note: All OpenStax books are CC BY licensed (free to use)

**MIT OpenCourseWare:**
1. Visit https://ocw.mit.edu
2. Look for the course containing the resource
3. Download PDFs from course materials
4. All OCW content is CC BY-SA licensed

**Author Websites:**
1. Visit the author's website (URLs in CSV)
2. Look for "Download", "PDF", or "Book" section
3. Check the site for license terms

**GitHub Repositories:**
1. Visit the GitHub URL
2. Look for `releases/` or downloadable PDFs
3. Check the repository's LICENSE file

**Publisher Sites (e.g., Springer, MIT Press):**
1. Visit the book's page on the publisher website
2. Many offer free PDFs with free/open access labels
3. Check the book's metadata for license
