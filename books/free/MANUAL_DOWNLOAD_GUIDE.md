## How to Download All 35 (Browser Method)

**Step-by-step process:**

1. Open each URL in your browser
2. Look for one of these indicators:
   - "Download" button
   - "PDF" link
   - "Free PDF" text
   - Book icon with PDF label
3. Right-click → "Save as..." → Save to `books/free/` folder
4. Name the file descriptively (title + year)

**Example naming:**
```
precalculus_openstax_2nd_2021.pdf
calculus_strang_mit.pdf
deep_learning_goodfellow_2016.pdf
```

## License Quick Reference

| License | Meaning | Attribution | Commercial |
|---------|---------|-------------|------------|
| CC BY | Free, must attribute | Yes | Yes |
| CC BY-NC | Free, non-commercial | Yes | No |
| CC BY-SA | Free, must share alike | Yes | Yes |
| CC BY-NC-SA | Free, non-commercial, share alike | Yes | No |
| CC BY-ND | Free, no derivatives | Yes | Yes |
| Open Access | Free online, academic use | Check terms | Usually no |

Most resources here are **educational-use free**. Verify each license at the source URL.
